Belum ada proyek yang dibuka

Ekspor per proyek (PDF, EPUB, HTML, JSON, TXT) membutuhkan proyek aktif. Impor dan cadangan lengkap dapat digunakan kapan saja.

Ekspor & Impor

Proyek aktif: —

Tentang PDF: Ekspor PDF menggunakan dialog cetak browser. Setelah dialog terbuka, pilih tujuan “Save as PDF / Simpan sebagai PDF”. Untuk nomor halaman, aktifkan opsi “Headers and footers” pada pengaturan cetak. Hasil cetak (tata letak, ukuran, pemenggalan halaman) dapat berbeda antar browser dan pengaturan pengguna.

Ekspor PDF

Membuka dialog cetak dengan dokumen buku siap cetak: sampul, halaman judul, daftar isi, seluruh bab, dan bagian penutup. Pilih “Save as PDF” di dialog cetak.

Nomor halaman PDF dihasilkan oleh browser (aktifkan Headers and footers), bukan dihitung aplikasi.

Ekspor HTML Mandiri

Menghasilkan satu berkas .html yang bisa dibuka langsung di browser apa pun: berisi sampul, daftar isi dengan tautan internal, dan seluruh isi buku. Bisa juga dicetak menjadi PDF dari berkas tersebut.

Ekspor EPUB

Menghasilkan berkas .epub (EPUB 3) siap dibaca di Apple Books, Google Play Books, Kobo, atau Calibre — berisi sampul, halaman judul, daftar isi, dan seluruh bab beserta gambar lokalnya.

Ekspor Proyek (JSON)

Menyimpan seluruh data proyek aktif (metadata, bab, sampul, desain) sebagai berkas JSON untuk pencadangan atau pemindahan antar perangkat secara manual.

Ekspor Teks Biasa (TXT)

Menghasilkan berkas teks polos berisi seluruh naskah — berguna untuk pengolah kata lain atau kebutuhan penerbitan.

Impor Proyek (JSON)

Memuat berkas JSON proyek yang diekspor dari aplikasi ini. Berkas divalidasi lebih dulu; bila ID proyek sudah ada, Anda akan diminta memilih menimpa atau menyimpan sebagai salinan.

Cadangan Lengkap

Mengekspor semua proyek menjadi satu berkas cadangan JSON, dan memulihkannya kembali. Lakukan cadangan rutin — data browser dapat hilang bila riwayat/penyimpanan dibersihkan.

Integrasi AI (Opsional, via Backend Perantara)

Status: Belum dikonfigurasi

Aplikasi tidak menyimpan API key di peramban — key yang tertanam di kode klien dapat dicuri siapa pun. Karena itu AI dijalankan melalui backend perantara server-ai.js (disertakan dalam paket, butuh Node.js 18+) yang menyimpan key pada variabel lingkungan server:

Contoh: http://localhost:8787 atau alamat server Anda sendiri. Jalankan: AI_API_KEY=kunci_anda node server-ai.js

Bila backend sudah terhubung, tombol Asisten AI di editor menyediakan:

  • Menyusun kerangka buku otomatis
  • Mengembangkan isi bab dari catatan
  • Menyusun pendahuluan & kesimpulan
  • Menyederhanakan bahasa & memperbaiki tata bahasa
  • Membuat ringkasan & ide judul

Selama backend belum dikonfigurasi, tombol Asisten AI menampilkan panduan konfigurasi — bukan mengoperasikan fitur yang tidak ada. Semua fitur inti tetap berfungsi tanpa AI.

Cloud Supabase — Login & Sinkron Antar Perangkat (Opsional)

Status: Belum dikonfigurasi

Sambungkan proyek Supabase milik Anda sendiri agar bisa masuk (login) dan menyimpan salinan buku di cloud. Jalankan berkas supabase-schema.sql (disertakan dalam paket) pada SQL Editor Supabase terlebih dahulu — skrip itu membuat tabel, profil otomatis, dan keamanan RLS sehingga setiap akun hanya dapat mengakses datanya sendiri.

Kunci anon memang dirancang untuk dipakai di peramban dan aman selama RLS aktif — itulah fungsi skrip SQL yang disertakan. Jangan pernah menempel kunci service_role di sini.

Sinkronisasi buku — butuh koneksi aktif dan sudah masuk akun. Bila belum, tombol di bawah nonaktif (bukan tombol palsu). Data lokal (IndexedDB) tetap salinan utama; cloud adalah salinan tersinkron, versi terbaru yang menang, laporan selalu ditampilkan. Auto-sinkron: setelah masuk akun, setiap buku yang disimpan (termasuk simpan otomatis saat menulis) diunggah ke cloud otomatis beberapa detik kemudian — tanpa menekan tombol. Statusnya dapat dipantau lewat indikator di Dashboard (chip status + lencana pada setiap kartu buku).

Sinkron tidak menghapus: buku yang dihapus lokal akan muncul kembali saat Tarik dari Cloud. Untuk menghapus total, hapus di aplikasi dan di tabel book_projects Supabase Anda.
